# RAG 知识库检索规范

## 何时调用 `knowledge_query`

在回答以下类型问题之前，应优先调用 `knowledge_query` 检索课程知识库，而非依赖模型自身记忆：

- 概念定义、原理说明、事实性陈述
- 课程资料中的具体内容（图表数据、配置参数、算法步骤等）
- 学生询问"课件里提到的…"、"讲义里说的…"等明确指向课程材料的问题

**例外**：纯数学推导、编程语法、与课程资料无关的通识性问题可直接回答，无需检索。

## 检索模式选择建议

`mode` 参数控制检索范围，根据问题特点自行选择最合适的模式：

| 问题类型 | 推荐 mode | 原因 |
|---|---|---|
| 事实定义、参数查询 | `naive` | 纯向量，速度快，精度高 |
| 概念关系、跨章节综合 | `mix` | 向量 + 知识图谱，覆盖更广 |
| 不确定时 | `hybrid`（默认） | 自动平衡 |

> 这是**建议**，而非固定顺序。根据问题性质直接选择合适的 mode，无需先 naive 再 mix。

## `[置信度: 低]` 信号

当 `knowledge_query` 返回的内容末尾包含 `[置信度: 低]` 时，表示工具内部已尝试查询改写，但检索结果的相关性仍不足。

应对方式：
- 在回答中主动说明："当前课程资料中未找到高度相关的内容"
- 可进一步调用 `wikipedia_search` 或 `web_search` 补充外部信息
- 不得假装检索结果充分，不得基于低置信度结果做出确定性断言

## 引用格式

每条来自 `knowledge_query` 的陈述必须标注来源：

```
[简明直接的回答，1-3 段]

**参考来源**
[1] 《课程名》第 N 课：课时标题
[2] Wikipedia：条目名称
[3] 来源网页标题 — 域名
```

- 行内引用：`[1]`、`[2]` 紧跟在对应句子末尾
- 若无知识库命中且外部搜索也无结果：如实告知，建议参考教材相关章节
- **禁止**：无来源的事实性断言；引用课程内容不注明出处
